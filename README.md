# Future of Blockchain for Financial Transactions

This repository contains code and supporting files for the research project titled **"Future of Blockchain for Financial Transactions"**, submitted as part of the **Intro to Topics in FinTech** course at the **New Jersey Institute of Technology**.

## 📄 Project Overview

The goal of this project is to analyze how blockchain technology enhances **data security**, **regulatory compliance**, and **scalability** in the financial services sector. We conducted both a qualitative and quantitative analysis using case studies of Ripple, Quorum, and Ethereum-based DeFi platforms.

## 🧪 Methodology

The analysis is based on:
- Secondary data collection from credible public databases such as Statista, IBM Blockchain Pulse, and Chainalysis.
- Empirical analysis of security breaches, compliance records, TPS (transactions per second), and cost efficiency metrics.

### Platforms Analyzed:
- **Ripple** – Permissioned blockchain with high TPS and compliance.
- **Quorum (JPMorgan)** – Enterprise-grade Ethereum fork with strong regulatory integration.
- **Ethereum DeFi** – Public blockchain showing high decentralization but lower compliance and more frequent breaches.

## 📊 Contents of the Repository

- `analysis/` – Scripts used to evaluate empirical metrics (e.g., fraud rates, TPS comparison).
- `data/` – Input dataset used for comparison across blockchain platforms.
- `visuals/` – Generated charts and graphs from analysis.
- `final_paper.pdf` – Final version of the academic paper submitted.
- `requirements.txt` – List of required packages to run the scripts.

## 📈 Key Findings

- Ripple reduced fraud cases by 75% post-adoption.
- Quorum reported no major breaches since deployment.
- Ethereum DeFi platforms lost ~$3.2 billion in 2023 due to vulnerabilities.
- Permissioned blockchains outperformed public blockchains in compliance and uptime.

## 🔧 Technologies Used

- Python (for data visualization and analysis)
- Pandas, NumPy, Matplotlib
- Markdown and LaTeX (for documentation and formatting)
- Public data APIs and blockchain whitepapers

